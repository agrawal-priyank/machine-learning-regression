

## Regresión de Aprendizaje Automático: Modelos de Predicción de Precios de Venta de Viviendas

### Descripción
* Se implementó regresión lineal y el algoritmo de k vecinos más cercanos con optimización por descenso de gradiente para crear un modelo óptimo para predecir los precios de viviendas utilizando el conjunto de datos del condado de King, Seattle.
* Se realizó ingeniería y selección de características utilizando penalizaciones Lasso y Ridge para eliminar las características que tenían poco o ningún impacto en el error de la suma de cuadrados residuales.
